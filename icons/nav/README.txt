VOLCA TECH — Iconos de navegación

Incluye 7 iconos SVG: Inicio, Servicios, Proyectos, Cómo trabajamos, Sobre mí, Preguntas y Contacto.

Los SVG usan currentColor para que puedas definir los colores desde CSS.
Ejemplo:
.nav-icon { color: #8a96a5; }
.nav-item:hover .nav-icon { color: #ffffff; }
.nav-item.active .nav-icon { color: #ff5a18; }

Son vectores escalables sin pérdida de calidad.
