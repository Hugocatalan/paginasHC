# VOLCA TECH — Desarrollo Web Profesional & Soluciones Digitales

Web comercial oficial de **VOLCA TECH**, desarrollada en **React + Vite** con estética **Dark Premium / Tech**. Diseñada para presentar y comercializar servicios de desarrollo web profesional, sitios institucionales para empresas, desarrollos a medida y automatizaciones de procesos.

Fundador y responsable técnico: **Hugo Catalán** (Técnico Universitario en Programación, UTN).

---

## 🚀 Proyectos y Demostraciones Interactivas Incluidas

El sitio incluye **6 proyectos navegables en tiempo real** con mockups visuales y páginas dedicadas:

1. **Estudio Jurídico:** Presencia digital y captación de clientes para profesionales independientes.
2. **INNOVA Ingeniería:** Portal institucional corporativo para empresas de servicios y tecnología.
3. **Fitness & Performance:** Landing page de alta conversión para entrenadores y servicios con planes interactivos.
4. **SS Servicios Eléctricos:** Portal de ingeniería industrial con simulador interactivo de cotización y presupuesto de obras.
5. **Julio Mercado — Tiro Profesional (ANMaC ITB 7796):** Plataforma web para instructor oficial con catálogo de cursos y asistente para Legítimo Usuario (CLU).
6. **Hugo Catalán — Coaching & Levantamiento Olímpico:** Landing de marca personal deportiva con métricas de autoridad (50 medallas internacionales) y asesor de objetivos.

---

## 🛠️ Stack Tecnológico

- **Frontend:** React 18, JavaScript ES6+, HTML5 Semántico.
- **Estilos:** CSS3 Modular con variables de diseño, efectos de resplandor (*ambient glow*), animaciones fluidas y diseño 100% *Mobile-First*.
- **Empaquetado:** Vite 6 (build ultra rápido y soporte de assets relativos).
- **SEO & GEO:** Metadatos OpenGraph, Twitter Cards, Schema.org (JSON-LD) y `llms.txt` para motores generativos de IA.

## 💻 Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd "HC Web"
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
